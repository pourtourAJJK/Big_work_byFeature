# QuickTask

一个简洁的个人待办事项应用，支持任务的新增、编辑、完成、删除、筛选与搜索，数据保存在浏览器本地（localStorage）。

## 技术栈

- **React 19** + **TypeScript**
- **Vite 8** 构建工具
- **Tailwind CSS v4** 样式
- **localStorage** 数据持久化（无后端、无账号体系）

## 功能

- 任务展示（标题、分类、截止日期、完成状态）
- 新增任务（弹窗表单：标题、分类、截止日期）
- 编辑任务（更多菜单 → 编辑任务）
- 完成状态切换（圆形复选框，带删除线视觉反馈）
- 删除任务（带确认弹窗）
- 筛选（全部 / 待完成 / 已完成，带数量统计）
- 搜索（按任务标题模糊匹配）
- 空状态友好提示
- 空列表时展示 6 条示例任务，点击可预填到新增表单
- 首次打开时内置 12 条示例任务（本地无数据时展示，用于演示）
- 响应式设计（桌面端 + 移动端浮动按钮）
- 数据本地持久化（刷新页面不丢失）

## 运行

### 安装依赖

```bash
pnpm install
```

> 如果没有安装 pnpm：`npm install -g pnpm@10.34.3`

### 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:8443/

### 构建生产版本

```bash
pnpm build
```

构建产物输出到 `dist/` 目录。

### 预览生产构建

```bash
pnpm preview
```

## 已知限制

1. **数据仅保存在本地浏览器**：使用 localStorage，不支持跨设备同步。清除浏览器数据会丢失任务。
2. **无账号体系**：单用户本地使用，无注册/登录/多用户隔离。
3. **分类为自由文本输入**：无预设分类列表，用户自行输入。
4. **截止日期为必填项**：新增/编辑任务时必须选择截止日期。
5. **无批量操作**：不支持多选、批量删除/完成。
6. **无提醒通知**：截止日期仅用于展示，不触发系统通知。
7. **搜索仅匹配标题**：不搜索分类或日期。
